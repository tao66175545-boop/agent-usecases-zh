# 字段说明（复制本文件后改 `draft: false` 并重命名）

| 字段 | 说明 |
| --- | --- |
| `title` | 中文标题，简洁可检索 |
| `scene` | 场景标签：写作 / 设计 / 编程 / 运营 / 研究 / 个人效率 等 |
| `audience` | 目标使用者 |
| `tools` | 工具栈字符串数组 |
| `difficulty` | `入门` \| `进阶` \| `高阶` |
| `summary` | 列表页一句话摘要 |
| `source` | 真实公开 URL，或明确写 `待补链接`（禁止编造） |
| `sourceName` | 可选，来源站点名 |
| `steps` | 3–6 步可执行摘要 |
| `draft` | `true` 时不出现在站点列表 |

正文可写注意事项与边界条件。不要写虚假「已验证」声明。
